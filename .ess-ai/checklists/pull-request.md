# Pull Request Checklist

Use `prompts/deploy/02-pr-preparation.md`; the PR template in `.github/pull_request_template.md` has the same sections.

- [ ] Requirement
- [ ] What changed
- [ ] Files / modules affected
- [ ] Business impact
- [ ] API / DB / config / dependency impact
- [ ] Tests executed and actual results (attach evidence)
- [ ] Security considerations
- [ ] Deployment considerations
- [ ] Rollback considerations
- [ ] Known gaps and UNKNOWNs
- [ ] AI-assisted areas and AI tool used
- [ ] AI Change Report completed (`.ess-ai/reports/`)
- [ ] CI green: secret scan, lint/format, typecheck, tests, dependency audit, build
- [ ] Appropriate reviewer requested
