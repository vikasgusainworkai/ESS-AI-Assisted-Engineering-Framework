## Model selection guidance
- Simple, local, low-risk tasks: a focused or lower-cost model is fine.
- Large codebase analysis, migrations, architecture or security review: use a stronger model/tool.
- Customer or production work: only approved tools and accounts, regardless of task size.

## Never send to any AI tool
- Secrets, keys, passwords, tokens
- Production database dumps or unmasked customer data
- Anything classified above what the tool is approved for
