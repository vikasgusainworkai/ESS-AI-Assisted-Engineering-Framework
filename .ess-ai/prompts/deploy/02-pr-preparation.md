# PR Preparation

_When to use:_ Use after tests pass and before opening a PR.

```text
Prepare this change for Pull Request review.
First inspect the actual git diff.
Create a PR summary containing:
1. Requirement
2. What changed
3. Files/modules affected
4. Business impact
5. API/DB/config/dependency impact
6. Tests executed and actual results
7. Security considerations
8. Deployment considerations
9. Rollback considerations
10. Known gaps and UNKNOWNs
Do not invent test results or claim checks that were not executed.
```
