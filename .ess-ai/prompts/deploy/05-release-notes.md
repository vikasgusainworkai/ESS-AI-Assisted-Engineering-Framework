# Release Notes

_When to use:_ Use for the release/change record.

```text
Generate release notes from the actual implementation and git diff.
Include:
- release/change name
- requirement
- user-visible changes
- technical changes
- affected modules
- DB/API/config changes
- dependency changes
- tests executed
- known limitations
- deployment steps
- rollback steps
Use only information supported by the repository and actual test/deployment evidence.
```
