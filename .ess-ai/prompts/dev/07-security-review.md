# Security Review

_When to use:_ Use before staging or production.

```text
Review the current implementation for security risks before staging or production. Do not modify code yet. Check authentication and authorization, SQL injection, unsafe input handling, API exposure, secrets/tokens, database access, customer-data exposure, insecure dependencies, logging of sensitive data, and error responses. Identify each finding with severity, evidence, affected file, and recommended minimum fix. Do not claim the implementation is secure without evidence.
```
