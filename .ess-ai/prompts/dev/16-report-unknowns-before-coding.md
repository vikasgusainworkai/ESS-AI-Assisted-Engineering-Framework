# Report Unknowns Before Coding

_When to use:_ When AI does not have enough context.

```text
Review the requirement and project context. List every UNKNOWN that could materially affect architecture, database behavior, security, customer behavior, integration or production deployment. Do not guess. For each UNKNOWN, state what evidence or person/source is needed to resolve it. Do not implement decisions that depend on unresolved UNKNOWNs.
```
