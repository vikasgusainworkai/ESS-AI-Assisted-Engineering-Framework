# Create ESS AI Knowledge Document

_When to use:_ After completing a new reusable AI implementation (MCP, agent, RAG, integration, automation).

```text
Review the AI implementation I just completed and create an ESS AI Knowledge Hub implementation document.
Include: implementation name, purpose, problem solved, architecture/workflow, technologies and models, repository/project location, dependencies, configuration, APIs/MCP/tools, security considerations, testing/validation, example usage, reuse/extension instructions, limitations, owner/team and date.
Use only evidence available in the project. Do not invent missing information. Mark missing details as UNKNOWN. Keep the document practical so another ESS developer can understand it and reuse the implementation.
Format the result as a clean implementation document ready to publish to the ESS AI Knowledge Hub.
```
