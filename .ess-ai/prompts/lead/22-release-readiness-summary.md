# Release Readiness Summary

_When to use:_ Before staging/UAT/production approval.

```text
Create a release-readiness summary from the available evidence. Check requirement completion, tests, regression results, security review, Git/PR status, database changes, configuration, deployment steps, rollback plan, monitoring and known issues. Mark each item VERIFIED, NOT VERIFIED or UNKNOWN. Do not state that production is ready unless the evidence supports it.
```
