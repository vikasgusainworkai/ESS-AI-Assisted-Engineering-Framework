# Unit Test Generation

_When to use:_ For a function, service, utility or component.

```text
Create unit tests for the implementation below.
Cover:
- normal valid inputs
- boundary values
- empty/null values where applicable
- invalid inputs
- expected exceptions/errors
- important business rules
- duplicate or repeated calls where relevant
First inspect the existing test style and framework. Reuse existing fixtures and helpers.
Do not change production code just to make the tests pass.
Run the tests after creating them.
Report exactly what was executed and the actual result.
```
