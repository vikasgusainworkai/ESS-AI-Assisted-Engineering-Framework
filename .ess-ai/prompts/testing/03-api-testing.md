# API Testing

_When to use:_ For REST/API changes.

```text
Review this API implementation and create a complete API test set.
Cover:
- valid requests
- missing required fields
- invalid data types
- boundary values
- invalid business conditions
- authentication and authorization where applicable
- expected status codes
- response schema
- error response format
- unexpected input
- regression cases
Use the project's existing API test framework if available.
Run the tests and show actual results.
Do not claim success without execution evidence.
```
