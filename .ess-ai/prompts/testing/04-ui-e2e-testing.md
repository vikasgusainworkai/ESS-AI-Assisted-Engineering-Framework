# UI / E2E Testing

_When to use:_ For React or screen-level business flows.

```text
Create an end-to-end test plan for this user flow.
Start from the user's entry point and cover:
1. Page/screen load
2. Required fields
3. Valid input
4. Invalid input
5. Boundary values
6. Save/submit behavior
7. Success response
8. Error response
9. Navigation after completion
10. Refresh/back/retry behavior where relevant
Identify selectors and test data needed.
Use existing E2E/browser test conventions.
Run the test and provide evidence for each failed or passed scenario.
```
