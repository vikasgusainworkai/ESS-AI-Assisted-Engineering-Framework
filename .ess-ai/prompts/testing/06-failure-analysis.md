# Failure Analysis

_When to use:_ Use when an AI-generated test fails.

```text
Analyze this test failure.
Do not immediately rewrite the code.
1. Explain what the test expected.
2. Explain what actually happened.
3. Identify the root cause.
4. Determine whether the issue is in code, test, test data, configuration or environment.
5. Propose the minimum required fix.
6. Apply the fix only after explaining the reasoning.
7. Run the failed test again.
8. Run relevant regression tests.
Do not modify unrelated code.
```
