# Smoke Test Before Demo

_When to use:_ Quick check before sharing a build with a customer or team.

```text
Run a smoke test for the current build.
Verify:
- application starts
- required configuration is available
- login/authentication works
- primary screen loads
- key API responds
- primary business action works
- database connection works where required
- no obvious console/runtime errors
Do not make broad changes.
Report PASS/FAIL for each check with actual evidence.
```
