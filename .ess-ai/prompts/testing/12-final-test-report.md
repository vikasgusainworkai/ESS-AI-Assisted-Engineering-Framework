# Final Test Report

_When to use:_ Use as the final verification step before PR/review.

```text
Prepare the final test report for this change.
Include:
1. Requirement tested
2. Files/features changed
3. Tests added or updated
4. Tests actually executed
5. Passed count
6. Failed count
7. Skipped count
8. Regression tests executed
9. Evidence available
10. Known gaps
11. Remaining risks
12. UNKNOWNs
Separate executed evidence from assumptions. Do not state “tested” unless the relevant tests were actually run.
```
